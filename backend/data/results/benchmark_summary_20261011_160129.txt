  aes_192_CBC: 3.62 ms encrypt, 276.21 MB/s

EdDSA Results:
  eddsa_Ed25519: 0.06 ms sign, 16854 sig/s
  eddsa_Ed448: 1.65 ms sign, 607 sig/s

Hyperledger Results:
  invoke: 25.06 ms latency, 100 TPS
  query: 15.56 ms latency, 500 TPS

Recommendations:
  - AES-256-GCM recommended for high-security data encryption in cloud storage. Provides authenticated encryption with excellent performance.
  - AES-128-GCM suitable for less sensitive data with lower computational overhead.
  - Ed25519 recommended for digital signatures - excellent performance, strong security (128-bit), and resistance to side-channel attacks.
  - Ed448 provides higher security margin (224-bit) for long-term protection but with ~2x computational cost.
  - Hyperledger Fabric suitable for multi-party cloud deployments requiring audit trails and tamper-proof logs. Trade-off: higher latency vs. centralized DB.
  - Consider Raft consensus for production deployments; Kafka for high-throughput needs.
  - Hybrid approach: Use AES-256-GCM for data encryption, Ed25519 for authentication, Hyperledger for audit logging in multi-tenant cloud environments.
